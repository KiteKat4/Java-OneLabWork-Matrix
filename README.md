# Лабораторная работа #1 по Java (Матрицы) (Ильичев Леонид 25КНТ-1)

Задание:

  Написать класс для работы с матрицами комплексных чисел. В классе должны быть методы,
позволяющие сложить, перемножить, разделить матрицы (при возможности), транспонировать и вычислить определитель. 
К классу должен прилагаться консольный интерфейс, позволяющий создать матрицу и задать операцию.
